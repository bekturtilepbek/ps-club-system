# PS-клуб: вопросы к владельцу

## Открытые

### 1. Локальный вариант или гибрид

Главное архитектурное решение. Нужно к запуску пилота.

**Локальный** — всё работает на ПК кассы.
- Работает без интернета
- Из дома владелец видит только Телеграм
- Если ПК кассы сломается — данные восстанавливаются только из бэкапа
- Бесплатно

**Гибрид** — данные и интерфейс на сервере в интернете, в клубе только маленькая программа для розеток (с фазы 2).
- Владелец из дома видит всё то же, что на кассе
- Поломка ПК кассы ничего не теряет — открыли браузер на другом компьютере
- Обновления без приезда в клуб
- Без интернета: уже идущие сессии досчитаются, новые начать нельзя
- Около $6 в месяц за сервер

Для сравнения: подписка на 6 устройств в LANGAME — около 3 600 руб. в месяц.

### 3. Модели телевизоров и тест

Точная модель TCL — с наклейки на задней панели или из меню.

**Тест** (минута, без программы):
1. Включить ТВ пультом, чтобы показывал приставку
2. Выдернуть вилку телевизора из розетки, не выключая пультом
3. Подождать 10–15 секунд, вставить обратно

Смотрим:
- включился ли ТВ сам, без пульта
- что показывает: приставку или главный экран Android TV
- сколько секунд грузился

Если не включился — поискать в настройках ТВ поведение при подаче питания («Система» → «Питание»), или включить T-Link на ТВ и «Связь с устройством HDMI» на PS5, потом повторить тест и нажать кнопку PS на геймпаде.

От результата зависит, подойдут ли умные розетки.

## Решено

| Вопрос | Решение |
|---|---|
| Открытое время | поминутно, итог округляется до сома |
| Продление пакета | гость выбирает другой пакет или открытое время |
| Время на выбор игры | 3 минуты при старте; ушёл за это время — бесплатно |
| Пакет перед закрытием | предупреждение, решает админ |
| Фискализация | пока не нужна, возможно в будущем |
| Безнал | на личный номер владельца |
| Учёт остатков бара | пока не нужен, возможно в будущем |
| Учёт постоянных гостей | пока не нужен, возможно в будущем |
| Телеграм | сводка при закрытии дня, напоминания, «что в зале», алерты по розеткам; уточним по ходу |
| Бесплатная игра | под общим аккаунтом, с пометкой причины |
| Подмена | на пару часов посреди дня; передача кассы пока не нужна |
| Часы работы | открытие и закрытие дня вручную; график как ориентир |

## Выяснить на месте (техническое)

- **WiFi.** Подключаются ли гости к той же сети, что и розетки. Если да — нужна отдельная гостевая сеть, иначе гость в сети теоретически может управлять розетками.
- **ПК кассы.** Примерный возраст, версия Windows, пользуется ли им владелец для чего-то ещё.
